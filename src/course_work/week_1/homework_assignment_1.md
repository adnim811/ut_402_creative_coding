# Homework Assignment \#1: Introduction Pull Request

## Description:
In this assignment, you will practice the process of contributing to an open-source project on GitHub by creating a pull request and adding a Markdown file to introduce yourself (for more information on Markdown, [click here](https://www.markdownguide.org/basic-syntax/)). This will help you become familiar with the basic steps involved in collaborating on GitHub, including cloning a repository, creating a branch, making changes, and opening pull requests. Most homework assignments for this course will be completed this way, so the earlier you get into the habit of commiting code changes and pushing to them to a branch on GitHub, the better :smile:

## Steps:
1. If you haven't already, clone this GitHub respository ("repo" for short)
2. Create a new branch using our classes naming convention - *\[your_initials\]/homework_assignment_week_#* (i.e. jos/homework_assignment_week_1)
3. In the src/coursework/week_1 directory, create a new Markdown file called *\[your_initials\]_introduction.md* (i.e. jos_introduction.md)
4. Add a few sentences about yourself and what you are most looking forward to learning in "Creative Coding" this semester.
5. Save and commit your changes.
6. Push your changes to our class' GitHub respository
7. Open a pull request and provide a descriptive title and description.
8. Once you have completed the above tasks, submit the link to your pull request in Canvas.
