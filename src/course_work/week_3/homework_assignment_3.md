# Homework Assignment \#3: Grocery List "App"

## Description:
In this homework assignment, you will build the core components of a grocery list. This includes:

Requirements:
- The list itself - using your best judgement, determine which data strucutre makes the most sense for a grocery list. Does an array work? An object? An array of objects? What properties does each item of a grocery list have?
- A function to add items to the list
- A function to edit items in the list
- A function to remove/delete items from the list

## Steps:
1. **Note:** Before checking out a new branch to start this assignment, ensure that you've pulled down the latest from the *main* branch and that you're *src/App.js* is in a "clean" state (as described in class)
1. Create a new branch using our classes naming convention - *\[your_initials\]/homework_assignment_week_#* (i.e. jos/homework_assignment_week_3)
2. Complete the above requirements in App.js
3. Save and commit your changes.
4. Push your changes to our class' GitHub respository
5. Open a pull request and provide a descriptive title and description.
6. Once you have completed the above tasks, submit the link to your pull request in Canvas.
