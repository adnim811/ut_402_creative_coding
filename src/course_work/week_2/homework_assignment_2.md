# Homework Assignment \#2: Calculator (continued)

## Description:
Building off of the calculator we built in class:
  - create a function that calculates the remainder when dividing two numbers (you can add this function in App.js, where we made our code changes during class)
  - add a CSS "id" to the `<input type="button" />` HTML element that is responsible for using this function (click [here](https://developer.mozilla.org/en-US/docs/Web/CSS/ID_selectors) for more info on CSS ids)
  - add that CSS "id" to "src/coursework/week_2/calculator.css", and add some custom styles to this button (i.e. change the background color, font-size, font-weight, border, etc.)

## Steps:
1. Create a new branch using our classes naming convention - *\[your_initials\]/homework_assignment_week_#* (i.e. jos/homework_assignment_week_2)
2. In App.js, create a new JavaScript function that calculates the remainder when dividing two numbers.
3. Add a CSS "id" to the `<input type="button" />` HTML element that is responsible for using this function. Then, add that CSS "id" to "src/coursework/week_2/calculator.css", and add some custom styles to this button (i.e. change the background color, font-size, font-weight, border, etc.)
4. Save and commit your changes.
5. Push your changes to our class' GitHub respository
6. Open a pull request and provide a descriptive title and description.
7. Once you have completed the above tasks, submit the link to your pull request in Canvas.
