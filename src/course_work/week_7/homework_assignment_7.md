# Homework Assignment \#7: Building a Line Graph of Daily COVID-19 Reported Cases in NYC (Feb 2020-May 2023)

## Description:
For this week's homework, you will build a D3 line graph using "nycCovid19DailyData.csv" (see "public" directory). This graph should represent the Covid-19 daily *case count* in New York City over time ("date_of_interest"). The graph should have a title, a y-axis label, should properly credit the source of the data (i.e. "City of New York"), and any other features you believe should be included. Feel free to reference notes from previous classes (see "src/course_work/week_7) and/or Google for relevant examples or documentation.
